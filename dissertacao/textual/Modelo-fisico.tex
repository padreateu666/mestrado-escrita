\section{Escoamento de Poiseuille entre placas planas}

O escoamento de Poiseuille em placas planas é utilizado para verificar a validade do modelo, avaliar as condições de contorno propostas e fazer estudos de independência de malha que são posteriormente transferidos para os casos mais complexos. O problema considerado utiliza as seguintes hipóteses simplificadoras:

\begin{itemize}
    \item bifásico
    \item desenvolvido
    \item unidirecional
    \item incompressível
    \item simetria no meio do domínio
    \item simetria em z
\end{itemize}


Na figura \ref{fig:poiseuille_plano} é mostrado o domínio e coordenadas consideradas. O problema é considerado unidimensional pois o perfil de velocidade varia apenas em $x$.
